# Philosopher

Bundled normal styles: Regular (400) and Bold (700), unmodified TTFs from
https://github.com/google/fonts/tree/main/ofl/philosopher.
Copyright and SIL Open Font License 1.1: OFL.txt.

Resources/PNFont is nested here so the Title and the pre-content default loading
screen can load the fonts before the content registry is available. No OS font
installation, network request, global theme or TextSettings change is needed.

Use is currently restricted to PNTitleScreen and the built-in default loading
presentation through PNTitleLoadingFonts. Other UI and custom mod screens retain
their existing fonts. The asset filenames identify weights; no synthetic bold.
